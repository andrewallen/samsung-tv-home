# Architecture

## Shape

A single-page Tizen web app. `index.html` loads plain ES5 scripts in order, and each one defines a global module (`window.HomeX`). `js/app.js` starts them all. There's no framework, bundler or build step. What's in the repository is exactly what runs on the TV.

```text
index.html
├── css/home.css          all styles (written for Chromium M47)
├── img/bg/               8 time-of-day photos, 1920x1080, one scene, aligned
├── fonts/                Hanken Grotesk (OFL)
├── config.xml            Tizen manifest: app ID, privileges, network access
└── js/
    ├── local.js          GENERATED by deploy.py from tvs.json (untracked): private settings
    ├── apps.js           the app list (a public example, replaced by local.js)
    ├── config.js         HomeConfig: saved settings in localStorage
    ├── sound.js          HomeSound: interface tones via Web Audio
    ├── glyphs.js         inline SVG icons (apps, weather)
    ├── sky.js            HomeSky: gradient sky fallback, tinted by time of day
    ├── scene.js          HomeScene: photo blending, per-scene effects, life events, explore mode
    ├── clock.js          HomeClock: time and date (12/24-hour, date styles)
    ├── weather.js        HomeWeather: Open-Meteo forecast, postcodes.io lookup
    ├── launcher.js       HomeLauncher: opens apps
    ├── list.js           HomeList: the vertical app list and glass highlight
    ├── inputs.js         HomeInputs: the TV Menu box (opens Samsung's home bar)
    ├── settings.js       HomeSettings: the settings overlay
    ├── lock.js           HomeLock: private mode (number-key code)
    ├── idle.js           HomeIdle: anti-burn-in drift and idle dimming
    └── app.js            starts everything, applies display options
tools/
├── tvlink.py             direct client for a TV's developer connection (sdb protocol)
├── deploy.py             build, sign, install on every TV in tvs.json; check; duid
└── tv-install.py         install on one TV
tvs.json                  the TVs, signing profile and private settings (untracked)
tvs.example.json          the format of tvs.json, with placeholders
```

## Screen layout (1920x1080)

- **Left column:** the app list. Items are fixed rows, and a glass "pill" highlight glides between them using `transform` only. Below the list is the **TV Menu** box, reached by pressing Down past the last app.
- **Right column:** the time, date, a short rule, the location and current weather, and a three-day forecast. It's centred vertically with `translate(-50%)`, so hiding parts re-centres it.
- **Overlays:** settings (Return), the status line (bottom left), the explore indicator (bottom centre), and the idle dimmer.

## The scene system (`js/scene.js`)

**Background.** Eight photos are placed on the day, anchored to the real sunrise and sunset from the forecast. The two images either side of "now" are blended continuously, with the top layer's opacity set to the progress between them and a 30-second transition. Night holds from about two hours after sunset until shortly before pre-dawn. If the background is fixed in settings, that image is used instead.

**Per-scene effects.** The `SCENES` table gives each time of day its own settings:

| Field | Effect |
| --- | --- |
| `sun` | position, radius, colour and strength of the glow over the sun or moon |
| `glint` | colour and strength of light glinting on the lake |
| `stars` | strength of the twinkling star overlay (night, pre-dawn, dusk) |
| `fog`, `fogRgb` | strength and colour of fog wisps over the valleys |
| `motes` | floating specks of light (low sun only) |
| `birds`, `shoot` | whether birds (by day) or meteors (dark sky) appear |
| `shadow` | cloud shadows sliding across the hills |

The `RAYS` table adds light rays fanning from a low sun (sunrise, golden hour, sunset).

**Life events.** Each time the scene changes, live or while exploring, a scheduler starts that scene's events within about 1.5 seconds and clears anything from the previous scene:

- **By day:** flocks of birds, with wings that beat and then glide (SVG path morph), geese in a V when the sun is low, and high jets leaving contrails.
- **By night:** meteors, with occasional short showers, aircraft with real strobe patterns, satellites, and a rare faint aurora.

**Always on:** a slow push-in on the photo, the sky drifting separately from the land (a masked copy of the sky), fog drifting with parallax, lake glints, and the breathing sun glow.

**Explore mode.** Left and Right cross-fade through the eight images on two preview layers (which only exist while exploring, to save graphics memory). The effects follow the scene shown. It returns to live 30 seconds after the last press.

## Private, per-household configuration

Anything that identifies the household stays out of git: the app list, default location, private-mode code, the app to start on, and the TVs' addresses. It lives in `tvs.json`, which is untracked, and is described by `tvs.example.json`. Before each build, `tools/deploy.py` writes its `local` section to `js/local.js` as `window.HOME_LOCAL`. That file is also untracked, and the other modules read their defaults from it. Without it, as in a public checkout, the app falls back to safe examples: a generic app list, London, and private mode off.

## Settings and state (`js/config.js`)

Everything a viewer changes is saved per TV in `localStorage` under `home.config.v1`: the location, app order, hidden apps, and display options (clock, date, weather, forecast, background, motion, sounds, private mode). It survives restarts and reinstalls of the same app ID, but not an uninstall.

## Engine constraints (Tizen 3.0, Chromium M47)

- **Not available:** CSS Grid, custom properties, `backdrop-filter`, flexbox `gap`, Intersection Observer, and modern JavaScript syntax. Write ES5 and check it with `npx acorn --ecma5`.
- **Available:** flexbox, CSS animations and transitions (with `-webkit-` prefixes alongside), SVG including SMIL `<animate>`, Web Audio, `fetch` and `XMLHttpRequest`, `localStorage`, and WebSocket.
- **Performance:** animate only `transform` and `opacity`, keep full-screen layers few, and avoid animating `box-shadow`. Fade a pre-drawn glow layer instead.

## Talking to the TV

- **Installing:** through the developer connection (port 26101, adb-style protocol). See `tools/tvlink.py` and [ADR 0003](adr/0003-direct-developer-protocol-client.md).
- **Opening apps:** `tizen.application.launch(appId)`, with a fallback to the TV's local REST service on `127.0.0.1:8001`.
- **Number keys:** must be requested with `tizen.tvinputdevice.registerKey()`, using the `tv.inputdevice` privilege.
